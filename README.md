# Análisis de sentimientos en español con RNN

Notebook académico de aprendizaje profundo para clasificar reseñas en español con TensorFlow/Keras.

## Contenido

El notebook incluye preparación de datos, entrenamiento y evaluación de un clasificador de sentimientos, además de una interfaz interactiva para introducir reseñas. Se utilizan NumPy, pandas, TensorFlow, Matplotlib, scikit-learn, datasets e ipywidgets.

## Ejecutar

Crear un entorno virtual, instalar `requirements.txt`, abrir Jupyter y ejecutar las celdas de `RNN_Sentimiento_Espanol_v2.ipynb` en orden. Las dependencias se listan sin fijar versiones porque el entorno original no incluía un archivo de versiones recuperable. El notebook puede descargar conjuntos de datos y entrenar modelos; revisar consumo de memoria y recursos antes de ejecutarlo.
